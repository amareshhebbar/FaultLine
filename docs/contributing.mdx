## Ownership

| Area | Owner |
| :--- | :--- |
| `platform/` | Platform owner |
| `engine/` | AI owner |
| `docs/`, `README.md`, `ROADMAP.md` | Both |

## Working rules

* One branch per task, small pull requests, the other owner reviews
* Keep the contract stable: service names, the chaos API, the ground truth row
* Every new fault kind ships with a note on how it looks from outside
* Every number in docs links to a result file
* Commit messages describe the change in plain words, with the author as the only signature
