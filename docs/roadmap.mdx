<Steps>
  <Step title="Phase 0: Scaffold" icon="check">
    Repo tree, README, banner, docs, roadmap. **Done.**
  </Step>
  <Step title="Phase 1: Walking skeleton">
    Three services with telemetry, chaos with `latency` and `error`, baseline detective, verifier, first 20 run score.
  </Step>
  <Step title="Phase 2: Reliable platform and agent">
    Queue, outbox, saga, idempotency, retries, breakers, cache. LLM tool calling agent. Zero duplicate charges under 10x redelivery.
  </Step>
  <Step title="Phase 3: Fault catalogue and RAG">
    Ten fault kinds, three more services, RAG over runbooks and code, 500 labelled incidents.
  </Step>
  <Step title="Phase 4: Kubernetes, CI/CD and fine tuned model">
    Helm, kind, GitHub Actions with a smoke eval. Small signal compression model on HuggingFace.
  </Step>
  <Step title="Phase 5: Results and launch">
    500 run eval, load test numbers, results page, blog post, demo video.
  </Step>
</Steps>
